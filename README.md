# VLN-AVP project page

Official project page for:

**VLN-AVP: Zero-Shot Vision-Language Navigation with Hybrid Long-Short-Term Memory for Autonomous Valet Parking**

- Project page: https://vln-avp.github.io/
- Paper: https://arxiv.org/abs/2607.17767

## Local preview

The site is static and can be served from this directory with any local HTTP server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` — page content and academic metadata
- `static/css/index.css` — responsive visual design
- `static/js/index.js` — BibTeX copy interaction
- `static/images/paper/` — web-ready figures derived from the paper
